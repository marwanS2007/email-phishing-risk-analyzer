## What I Learned

This project helped me understand how phishing emails can be analyzed using multiple security indicators instead of relying on a single suspicious word or link.

While building this project, I practiced:

- Creating and organizing multiple Python functions
- Using lists and dictionaries to organize phishing indicators
- Using regular expressions to identify patterns in email content
- Analyzing sender email addresses for suspicious characteristics
- Examining email subject lines for urgency and pressure tactics
- Detecting credential-related and account-security language
- Extracting URLs from email messages
- Using URL parsing to examine domains and links
- Detecting shortened URLs and insecure HTTP links
- Building a weighted risk-scoring system
- Classifying emails as LOW, MEDIUM, or HIGH risk
- Generating security findings that explain why an email was flagged
- Understanding common social-engineering techniques used in phishing attacks

This project gave me hands-on experience combining Python with cybersecurity concepts such as phishing detection, social engineering, URL analysis, email security, and rule-based threat assessment.
